# דף התחברות — חוקי-מוצר/לוגיקה

ר' כוונות בקובץ [`login.md`](./login.md).

1. **התחברות אופציונלית תמיד.** משתמש-לא-מחובר ממשיך להשתמש
   באפליקציה במלואה, מקומית/אופליין — אסור להוסיף חסימה שתחייב
   התחברות לפני שימוש בליבת-האפליקציה (רשימה/ניווט).
2. קוד-בית (household code) הוא **הזהות היחידה** של "קבוצה לקניות
   משותפות" — אין ליצור concept נפרד של "קבוצה"/"team" בלי לאחד
   אותו עם household קיים.
3. כשל-שרת בהתחברות/הרשמה נופל בחזרה להודעת-שגיאה ברורה (`.login-error`),
   לא שובר את שאר האפליקציה — המשתמש יכול לסגור ולהמשיך במצב-לא-מחובר.
4. סשן מאוחסן כטוקן אטום (לא JWT); אין להחזיר מידע רגיש (hash של
   סיסמה וכו') בתגובת ה-API.
