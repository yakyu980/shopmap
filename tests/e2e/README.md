# בדיקות E2E עם Playwright

## בדיקה מקומית

```bash
npx playwright install chromium
npm run test:e2e
```

הבדיקה הראשונית אינה משנה נתונים: היא בודקת את מסך ההתחברות ואת זרימת "שכחתי סיסמה".

## בדיקות מול Supabase QA

לבדיקות הדורשות משתמשים, מריצים את שרת ה־Express מול פרויקט Supabase נפרד ומגדירים את משתני הסביבה של השרת מתוך `server/.env` מקומי. אין להכניס מפתחות ל־Git. את משתמשי הבדיקה ונתוני הקבוצות יש ליצור ב־seed ייעודי לפני הוספת תרחישי login → group → home.
